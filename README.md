# Cassino Gauss

Jogo educativo (fichas fictícias) criado para um seminário de Probabilidade e Estatística sobre as distribuições **Uniforme**, **Exponencial** e **Normal (Gauss)**.

- 🎡 Roleta: distribuição uniforme
- 💣 Bomba-relógio: distribuição exponencial e falta de memória
- 🔴 Plinko: distribuição normal e Teorema Central do Limite

Cada jogo tem uma simulação de 2000 apostas que mostra a Lei dos Grandes Números: a casa sempre ganha.
